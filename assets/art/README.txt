SHDWYI Gallery — artwork drop folder
=====================================

The 8 frames read these exact filenames:

  abyss.png         (PROJECT: ABYSS — Game)
  echoes.png        (ECHOES BEYOND THE DEAD — Game)
  red-shadow.png    (RED SHADOW — 3D Character)
  ren-ashveil.png   (REN ASHVEIL — Character Concept)
  requiem.png       (REQUIEM — Digital Art)
  rebirth.png       (REBIRTH — Digital Art)
  blueey.png        (BLUEEY — 3D Character)
  forge.png         (FORGE AI COACH — App)

Ideal size:  1024 x 1602 px, portrait (width : height = 0.639)
Format:      PNG (current setup); ~1-2 MB each is fine

Any near-portrait image works — the site center-crops to fill the
frame without stretching.

IMPORTANT: after replacing any image, bump the ART_VERSION number in
gallery-demo_v6.html (search for ART_VERSION) so browsers refetch it.

When deploying to GitHub Pages, upload this assets/ folder alongside
index.html — the paths are relative and keep working.
