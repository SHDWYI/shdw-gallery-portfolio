SHDWYI Gallery — artwork drop folder
=====================================

Put your 8 project images in this folder with these exact names:

  abyss.png         (Project 01 — ABYSS, Underwater Horror)
  echoes.png        (Project 02 — ECHOES, Beyond the Dead)
  coach.png         (Project 03 — COACH, AI Productivity)
  chronos.png       (Project 04 — CHRONOS, Interactive Fiction)
  requiem.png       (Project 05 — REQUIEM, Visual Design)
  rebirth.png       (Project 06 — REBIRTH, Branding)
  ren-ashveil.png   (Project 07 — REN ASHVEIL, Character Design)
  forge.png         (Project 08 — FORGE, AI Coach)

Ideal size:  1024 x 1602 px, portrait (width : height = 0.639)
Format:      PNG (current setup); ~1-2 MB each is fine

Any image close to portrait works — the site center-crops to fill the
frame without stretching. A frame whose image is missing simply keeps
its placeholder art, so you can add these one at a time.

When deploying to GitHub Pages, upload this assets/ folder alongside
index.html — the paths are relative and keep working.
