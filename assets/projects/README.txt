SHDWYI Gallery — project page images
====================================

Images shown on each project's page (the screen that opens when you
press E at a painting). Downloaded from shdwyi.framer.ai in Oct 2026.

  abyss/gallery/              40  key art, title screen, environments, UI
  abyss/behind-the-scenes/    10  concept sketch, layout, sculpts, porthole
  echoes/gallery/              9  gameplay
  red-shadow/gallery/          8  01–05 landscape, 06–08 portrait
  blueey/gallery/              3
  forge/gallery/               9  01 promo poster, 02–09 app screens

Files are numbered in the order they appear on the page. Every folder
has a thumbs/ subfolder with small JPG copies (max 640px) that the page
tiles use, so the page stays fast; the originals load only when someone
opens an image full-screen.

To add an image: put it in the right folder with the next number, make
a matching thumbs/NN.jpg (any small copy works), and add the filename to
that project's list in gallery-demo_v6.html (search for projectImgs).
To reorder: just reorder the filenames in that list.
